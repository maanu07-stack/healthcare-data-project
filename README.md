# Diabetes Prediction using Machine Learning

This project implements a machine learning predictive model to analyze patient healthcare records and predict diabetes progression using Linear Regression.

## Project Overview
* **Dataset:** Uses the built-in diabetes dataset from `scikit-learn` containing patient physiological indicators.
* **Model Used:** Linear Regression (`sklearn.linear_model.LinearRegression`)
* **Evaluation Metrics:** 
  * R2 Score: ~0.45
  * Mean Squared Error (MSE): ~2900.19

## Technologies Used
* Python
* Pandas / Scikit-learn
* Jupyter Notebook (VS Code)

## How to Run
1. Clone the repository or download the `.ipynb` file.
2. Open it in VS Code or any Jupyter environment.
3. Run the cells sequentially to view data loading, model training, and performance evaluation.
